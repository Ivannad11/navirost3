# React Проект

Современный React проект созданный с использованием следующих технологий:

## 🛠️ Стек технологий

- **React 19** - UI библиотека
- **TypeScript** - Типизация JavaScript
- **Vite** - Быстрый сборщик проекта
- **TailwindCSS** - CSS фреймворк для стилизации

## 🚀 Быстрый старт

### Установка зависимостей
```bash
npm install
```

### Запуск проекта в режиме разработки
```bash
npm run dev
```

### Сборка проекта для продакшена
```bash
npm run build
```

### Предпросмотр собранного проекта
```bash
npm run preview
```

### Проверка кода
```bash
npm run lint
```

## 📁 Структура проекта

```
src/
├── main.tsx      # Точка входа приложения
├── App.tsx       # Главный компонент
└── index.css     # Глобальные стили с TailwindCSS
```

## ✨ Возможности

- ⚡ Быстрая разработка с Hot Module Replacement
- 🎨 Современный дизайн с TailwindCSS
- 📱 Полностью адаптивный интерфейс
- 🔒 Строгая типизация TypeScript
- 🌐 Поддержка русского языка

## 🎯 Что внутри

Приложение содержит интерактивный счётчик с красивым интерфейсом:
- Увеличение/уменьшение значения
- Сброс счётчика
- Плавные анимации и переходы
- Современный градиентный фон

## 🛠️ Дальнейшая разработка

Проект готов к расширению. Вы можете:
- Добавлять новые компоненты в папку `src/components/`
- Создавать страницы в `src/pages/`
- Настроить роутинг с React Router
- Добавить state management (Redux, Zustand)
- Интегрировать API для работы с данными

Приятной разработки! 🚀
